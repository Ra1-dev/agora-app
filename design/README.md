# Design assets

Everything here comes from the approved AGORA identity. Do not redraw or approximate: use these files.

- `tokens/agora.css` — CSS variables `--ag-*` (colours for light "Paros" and dark "Night", type, spacing, radii, strokes, shadows, layers, motion, track rules, event layer). Import once at the app root.
- `tokens/agora.tokens.json` — the same values in W3C Design Tokens format, with descriptions of the track, motion and event rules.
- `brand/` — logo (`agora-logo-*`, small version `agora-logo-small-*` for 10–24px), Ω mark, hero wordmark W1 (`agora-hero-*`, only on the AGORA welcome screen), seal B (certificates), app icon and favicon; `brand/png/` has favicon.ico, apple-touch-icon, PWA icons.
- `icons/` — 57 UI icons + sprite `agora-icons.svg` (24 grid, stroke 1.75, `currentColor`).
- `agora-cover.mjs` — default event cover generator (see `docs/design-decisions.md` §7).
